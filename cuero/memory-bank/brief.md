# Project Brief

Building a React web application for a leather goods company with personalized marketing content and video integration. The system includes personalization features, urgency timers, and dynamic content replacement based on URL parameters.

The application is built with Vite, React, TypeScript, and Tailwind CSS, using shadcn/ui components for the design system. It includes features for personalized branding, video modal integration, and expiration-based access control.

Key features include:
- Personalized content based on URL parameters
- Video player integration with Streamable
- Dynamic logo replacement
- Urgency timer functionality
- Responsive design with mobile-first approach
